# Taller integrador de programación por capas

TurnoLab es el proyecto de reservas de equipos de laboratorio del módulo LPPC de INFOTEP, sede San Juan del Cesar. La entrega incluye una aplicación web local en Python, una base de datos SQLite y material de sustentación para el grupo.
